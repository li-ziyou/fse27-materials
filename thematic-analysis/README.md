# Thematic analysis

coding-table.csv and codebook.md contain the 64 retained codes, their interpretive boundaries, and their recorded review status. additional-applications.csv lists existing code applications across materials. These files exclude original quotations, transcripts, and private links.

Run `python3 thematic-analysis/summarize.py` from the package root to regenerate code-summary.csv. The script summarizes existing coding decisions; it does not generate codes automatically from the undisclosed interviews.

manuscript-themes.csv contains the six themes and participant counts reported in the current manuscript. The available coding materials do not independently reconstruct all these counts; the final mapping between codes and themes remains to be completed. The shared P001/P011 material must not be counted as two independent sources of evidence.
